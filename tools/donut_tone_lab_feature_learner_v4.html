How this learner works · limits · reset tools

Prediction: sRGB pixels → histogram, exposure, colour and spatial measurements → one globally trained 16 / 8 unit neural network → gamma and brightness. Filenames, scene IDs and ratings are never prediction inputs. A no-change head is learned from exact approvals; its score is not a calibrated confidence probability. Small predicted curves can snap to exact identity.

Feedback: Good saves the first approved model curve as a stable target. Later Good votes do not move it. Original is already right teaches identity. Fine-tune target is explicitly a manual preview; Save target replaces that example’s learning target, not its model output. Directional votes without a target constrain the midtone result; they cannot fully specify two sliders. For an image with a saved target, training keeps fitting that target until you explicitly change or remove it.

Validation: groups, not individual files, are assigned to training or validation. Both variants of a scene must share a group. Validation labels never enter weight updates, feature normalization or epoch selection; they are reported separately. Repeatedly choosing settings after looking at validation makes it a development set, not a final independent test. Hold out another folder for your final check.

Limits: analysis uses a 256-pixel-long-edge, browser-decoded sRGB proxy. Local contrast features depend on that scale. The output is a global RGB power curve (exponent ⅓–3, gain 0.8–1.25), not local exposure editing, contrast recovery or white-balance correction. Measurements cannot establish artistic intent. An untrained model returns the original. Native lightbox rendering uses a 16 MP / 8192-pixel safety limit and labels reduced previews. PNG/JPEG/WebP/AVIF/BMP are accepted when the browser can decode them; animated images are excluded.

Persistence: example features, targets and weights are saved locally, not image pixels. Reopen a folder to view it. Export session is the portable backup; Export model only carries weights and normalization, with no rating history. A local HTML file cannot enumerate sibling images silently.
